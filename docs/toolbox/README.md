## 007 — NotebookLM prompt patterns (paraphrased from shared screenshots)

1. **Core Meaning Extractor** — Analyse uploaded material and formulate five essential questions covering foundations, key ideas, connections and practical applications.
2. **Structural Thinking Builder** — Formulate five deeper questions that, when answered, explain the material's main ideas and purpose.
3. **Insight Discovery Engine** — Identify surprising or important findings from supplied sources, with supporting quotations and explanations.
4. **Guided Insight Deep-Dive** — Extract insights on a specified topic and angle, explicitly excluding irrelevant areas; include direct quotes when available.
5. **Interactive Quiz Generator** — Two-speaker, ten-question mixed multiple-choice and true/false quiz, including corrections and a performance summary.
6. **Multilingual Podcast Creator** — Draft a natural, conversational episode in a specified language, retaining English only where technical terminology requires it.
7. **Product Manager Lens** — Turn internal documents into a decision memo with user evidence, feasibility constraints, blind spots and clarification questions.
8. **Scientific Analysis Mode** — Evaluate methodology, data quality, contradictions and evidence limitations; report key findings, strengths/weaknesses and conflicting evidence.
9. **High-School Translator Mode** — Explain complex material at approximately age-12 level, including one-sentence summary, analogy, vocabulary and true/false checks.

These are **prompt patterns**, not independently installed NotebookLM features. Source-grounding and quotations must be checked against original materials. The screenshot's product name “Gemini Notebook” is not treated as a verified product name; Google's product is NotebookLM.
